# OnBOARD CBSE 2027 Official Curriculum Library

Structured repository of Class 12 CBSE curriculum assets for **OnBOARD**, including official NCERT textbooks, handwritten teacher revision notes, and daily practice problem (DPP) question sheets.

---

## Directory Structure

```
OnBoard-files/
├── index.json                    # Machine-readable curriculum manifest
├── ncert/                        # Official CBSE NCERT Textbooks
│   ├── english/
│   │   ├── flamingo/             # Prose & Poems (The Last Lesson, Lost Spring, etc.)
│   │   └── vistas/               # Supplementary Reader (The Third Level, The Tiger King, etc.)
│   ├── physics/
│   │   ├── part1/                # Ch 1 to 8 (Electrostatics to EM Waves)
│   │   └── part2/                # Ch 9 to 14 (Optics to Semiconductors)
│   ├── chemistry/
│   │   ├── part1/                # Solutions, Electrochem, Kinetics, d&f, Coordination
│   │   └── part2/                # Organic Chemistry (Haloalkanes to Biomolecules)
│   ├── mathematics/
│   │   ├── part1/                # Relations & Functions to App of Derivatives
│   │   └── part2/                # Integrals to Probability
│   ├── biology/                  # 13 Core Chapters
│   └── physical_education/       # Class 12 Complete Textbook
├── notes/                        # Handwritten Revision Notes
│   └── english/
│       ├── flamingo/             # Chapterwise teacher notes with board highlights
│       └── writing_section/      # Letters, Notices, Articles, and Reports
└── dpp/                          # Daily Practice Problems (DPP)
    └── english/
        └── flamingo/             # High-yield chapterwise practice question sets
```

---

## Direct CDN Raw Access

Assets are served via GitHub's CDN:
`https://raw.githubusercontent.com/Marvelousshivam/OnBoard-files/main/<path-to-file>`

Example:
- The Last Lesson NCERT: `https://raw.githubusercontent.com/Marvelousshivam/OnBoard-files/main/ncert/english/flamingo/ch01_the_last_lesson.pdf`
- The Last Lesson Handwritten Notes: `https://raw.githubusercontent.com/Marvelousshivam/OnBoard-files/main/notes/english/flamingo/ch01_the_last_lesson_notes.pdf`
- The Last Lesson DPP: `https://raw.githubusercontent.com/Marvelousshivam/OnBoard-files/main/dpp/english/flamingo/ch01_the_last_lesson_dpp.pdf`
